# 🎨 ASCII Image Renderer (Rust)

ASCII Image Renderer adalah aplikasi CLI berbasis Rust untuk mengonversi gambar menjadi ASCII art.  
Aplikasi ini mendukung:

- Resize otomatis mengikuti ukuran terminal  
- Rendering cepat menggunakan parallel compute (Rayon)  
- Mode warna (ANSI True-Color)  
- Mode grayscale ASCII klasik

Program ini cocok sebagai mini-project untuk belajar Rust, terutama konsep:

- Image processing  
- Parallelism  
- CLI argument parsing  
- Terminal rendering  

---

## ✨ Fitur

### ✔ Otomatis menyesuaikan lebar dengan ukuran terminal  
Program membaca ukuran terminal dan menyesuaikan render dengan proporsi karakter ASCII.

### ✔ Parallel compute (lebih cepat)  
Menggunakan **Rayon** untuk mempercepat rendering dengan memproses banyak baris gambar secara paralel.

### ✔ Mode berwarna (true-color)  
Menggunakan ANSI escape code, sehingga ASCII art tetap mempertahankan warna gambar asli.

### ✔ Mode grayscale default  
Menghasilkan ASCII art hitam-putih klasik seperti renderer ASCII tradisional.

## 📦 Installasi

Clone repository:

```bash
git clone https://github.com/username/ascii-renderer.git
cd ascii-renderer
```

Build project:

```bash
cargo build --release
```

File executable akan berada di:

```
target/release/ascii_renderer
```

---

## 🚀 Cara Menjalankan

### 1. Mode grayscale (default)
```bash
cargo run -- path/to/gambar.png
```

### 2. Mode warna
```bash
cargo run -- path/to/gambar.jpg --color
```

### 3. Menggunakan executable langsung
```bash
./ascii_renderer foto.png
./ascii_renderer avatar.jpg --color
```
